# 0008 새 라이브러리 허용

- 상태: 확정 (2026-11-23, 설계서 추천안 채택)
- 결정: 아래 네 개만 새로 허용한다. 버전은 숫자로 고정한다(`latest` 금지).
  - 실행용: `immer`(실행 취소 패치, P5-1), `fflate`(프로젝트 파일 zip, P4-2)
  - 개발용: `@playwright/test`(회귀 스위트, P0-3), `@axe-core/playwright`(접근성 점검, P6-2)
- 이유: 실행 취소는 문서 전체 복제 대신 변경분(패치)만 저장해야 메모리와 속도가 안정된다. 큰 음원을 JSON/base64로 담으면 메모리가 두 배 이상 든다. 회귀 측정은 사람이 손으로 하면 지속되지 않는다.
- 영향: 개발용은 0단계, 실행용은 해당 단계 시작 시 `package.json`에 넣는다. 이 목록 밖의 라이브러리는 이 문서에 새 결정을 남기고 추가한다.
- 다르게 정하면: immer 없이는 직접 만든 구조 공유 갱신 함수와 스냅샷 이력을, fflate 없이는 자체 바이너리 묶음 형식을 쓴다(P4-2 대안).
