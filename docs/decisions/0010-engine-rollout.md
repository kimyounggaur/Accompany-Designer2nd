# 0010 엔진 교체 방식

- 상태: 확정 (2026-11-23, 설계서 추천안 채택)
- 결정: 새 오디오 엔진은 옛 엔진 옆에 나란히 두고, 주소 옵션 `?engine=v2`(또는 `localStorage["ad.engine"] = "v2"`)로만 켠다. 3단계 수용 기준을 모두 통과하면 기본값을 v2로 바꾸는 PR 하나를 내고, 1주 뒤 옛 엔진을 지우는 PR 하나를 낸다.
- 이유: 한 번에 교체하면 문제가 생겼을 때 되돌리는 방법이 PR revert뿐이다. 나란히 두면 옵션 하나로 즉시 되돌릴 수 있다.
- 영향: 3단계 전체(P3-1~P3-6). 옛 엔진 파일은 기본값 전환 후 1주 동안 삭제하지 않는다. 엔진 선택 옵션을 읽는 곳은 한 곳으로 제한한다(위치는 P3-1에서 정한다).
- 다르게 정하면: 한 번에 교체하면 일정이 짧아지지만 위험이 커진다.
