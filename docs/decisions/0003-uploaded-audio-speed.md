# 0003 올린 음원의 속도

- 상태: 확정 (2026-11-23, 설계서 추천안 채택)
- 결정: 올린 음원은 기본으로 원본 속도로 재생한다(WARP 꺼짐). BPM을 감지한 뒤 "프로젝트 템포로 맞추기"는 사용자가 고르는 선택으로 둔다(codex 브랜치에 이미 있음).
- 이유: 올리자마자 속도가 바뀌면 의도하지 않은 소리 변화로 느껴진다(보고서 B3, B4).
- 영향: P4-4(템포·WARP·BPM 마무리). `bpmDetector`는 회귀 테스트(`tests/bpmDetector.test.mjs`)로 고정한다.
- 다르게 정하면: P4-4의 기본값과 안내 문구가 바뀐다.
