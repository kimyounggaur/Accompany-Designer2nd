# 0005 저장 방식

- 상태: 확정 (2026-11-23, 설계서 추천안 채택)
- 결정: 브라우저 자동 저장(음원 포함)과, 음원을 담은 프로젝트 파일 두 가지를 함께 쓴다.
- 이유: 새로고침·탭 닫힘으로 작업을 잃지 않게 하면서(보고서 A4), 다른 기기로 옮기거나 백업할 수 있는 파일이 필요하다(A5).
- 영향: P2-4(자동 저장 서비스 분리), P4-2(`.adproj` 파일과 음원 재연결). 형식은 결정 0009.
- 다르게 정하면: 파일만 쓰면 P2-4가 줄고, 자동 저장만 쓰면 P4-2가 줄지만 기기 간 이동이 어려워진다.
