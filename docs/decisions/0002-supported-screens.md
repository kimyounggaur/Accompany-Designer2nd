# 0002 지원 화면

- 상태: 확정 (2026-11-23, 설계서 추천안 채택)
- 결정: 노트북 화면(너비 1280px 이상)을 먼저 지원한다. 휴대폰은 편집 전체가 아니라 "재생·녹음만" 되는 모드를 6단계(P6-5)에서 만든다.
- 이유: 타임라인 편집은 작은 화면에서 쓰기 어렵다. 반면 수업 현장에서는 휴대폰으로 반주를 틀고 녹음하는 수요가 있다(보고서 C9).
- 영향: P2-1(화면 틀)은 1024~1920px을 모두 검사하되 최적화 기준은 1280px 이상. P6-5가 390px 폭의 "재생·녹음" 모드를 맡는다.
- 다르게 정하면: P6-5의 범위가 바뀐다(편집까지 지원하면 L 규모로 커진다).
