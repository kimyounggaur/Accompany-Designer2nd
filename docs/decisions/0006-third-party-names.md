# 0006 타사 이름·아이콘

- 상태: 확정 (2026-11-23, 설계서 추천안 채택)
- 결정: 타사 프로그램의 이름과 아이콘(예: FL Studio 캡처·아이콘)은 쓰지 않고 자체 이름·아이콘으로 바꾼다.
- 이유: 공개 저장소와 공개 주소에 타사 상표·캡처가 남지 않게 한다(보고서 D2).
- 영향: P1-3(저장소에서 `Source/`, `00 Source/`, `flicon_*` 정리), P6-3(화면 문구·아이콘 정리).
- 다르게 정하면: 타사 표기를 유지하면 P1-3, P6-3이 사라지지만 상표 문제가 남는다.
